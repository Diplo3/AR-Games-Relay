# Проверка v0.3

Исходный репозиторий: Diplo3/AR-Games-Relay; база main `9c6bb43df7870ca44d71e07b5144b72233c7f98f` (v0.2). Проверены server.js, package.json, README и public/index.html перед изменениями.

Дата: 11 октября 2026. Локальные интеграционные проверки реальными WebSocket-соединениями. `node --test test/relay.test.js`: **7 passed / 0 failed**, штатное завершение процесса.

| Сценарий | Результат |
|---|---|
| Контракт v0.2, 100 быстрых команд | 100 событий HOST, 100 ACK, порядок 1–100 |
| 20 виртуальных телефонов, по 100 команд | 2000 уникальных событий, 1000 TEAM 1 и 1000 TEAM 2; очередь пуста, потерь 0 |
| Обрыв телефона, команда во время обрыва | Доставлена после reconnect; TEAM и sessionId сохранены |
| Пересоздание клиента с сохранённым хранилищем | Продолжен seq и сохранена TEAM |
| HOST отключён, ACK потерян, HOST возвращается | Доставка завершена, повтор не вызывает второе действие |
| Комната, неподходящая роль, null JSON, истёкшая команда | Изоляция комнат и ожидаемые ошибки |
| Перезапуск relay до ACK | Повтор доставлен и подтверждён без повторного действия HOST |
| Истечение очереди | Только просроченная команда учитывается потерянной |

Браузерная проверка: HOST и PLAYER TEAM 2 в двух вкладках; кнопка «100 импульсов» дала 100 отправленных / 100 полученных / 0 потерянных; обновление страниц сохранило ID, TEAM, счётчики и последовательность. Повторный тест продолжил сохранённую сессию.

Дополнительный тест опубликованного Render (11 октября 2026): 20 виртуальных телефонов, 10 в каждой команде, 100 команд на телефон. **2000 отправлено / 2000 принято / 2000 получено HOST / 2000 подтверждено телефонам, 0 потерь, 0 дублей.** RTT параллельных клиентов был 54 мс min / 318 мс avg / 5152 мс max. Это выявило лишнюю частоту широковещательных обновлений статистики под нагрузкой.

После теста добавлена локальная оптимизация: объединять room_stats в окне 100 мс и считать ожидающие команды инкрементально. Регрессионные проверки повторены: **7/7 passed**, локальный сценарий 20 × 100 команд завершился за ~521 мс. Эта оптимизация ещё не загружена в GitHub/Render; указанные публичные результаты 20 клиентов относятся к опубликованному коду до оптимизации.

Локальные RTT не являются измерением задержки Render или мобильной сети. Физические 20 телефонов, Wi-Fi/4G/5G, внешнее развёртывание Render и интеграция с реальной Electron-игрой в этой проверке не участвовали.
