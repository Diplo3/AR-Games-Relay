# Проверка v0.4

База исходников: `Diplo3/AR-Games-Relay`, main commit `8b9168517578c74bf6daf7336996e2d10d490488` (оптимизированная v0.3, проверенная пользователем на Render). Версия сохраняет путь v0.2 для 100/100 команд.

Проверено локально интеграционными WebSocket/HTTP тестами: `npm test` — **18 passed / 0 failed**.

| Сценарий | Результат |
|---|---|
| Старый протокол v0.2 | 100 команд, 100 событий HOST, 100 ACK |
| Нагрузка 50 телефонов, TEAM 1–50 | 5000 уникальных игровых команд, по 100 от каждой команды; все обработаны, потерь 0 |
| Список устройств | Полный список телефонов получает HOST; игрокам уходит только короткая сводка комнаты |
| Датчики при тех же 50 телефонах | 1000 образцов гироскопа, по 20 от каждой команды, переданы HOST; уникальность всех seq сохранена |
| Reconnect телефона и восстановление клиента | Очередь, TEAM, sessionId и seq сохранены |
| Игровое состояние HOST → комната / TEAM / устройство | Позднее подключение получает актуальные снимки; после рестарта relay HOST автоматически восстанавливает их |
| Возможности устройства | Список датчиков передан в `room_stats.devices[].capabilities` |
| HOST недоступен / потеря ACK / рестарт relay | Повторная доставка без повторного действия HOST |
| Асинхронный HOST handler | При ошибке нет ACK, событие доставляется повторно; после успешной обработки команда подтверждается |
| Комната, роли, некорректные и устаревшие сообщения | Изоляция и ожидаемые ошибки |
| Ограничение команд от одного устройства | После 200 команд/с сервер отвечает retryable rate-limit; команда не попадает в очередь обработки |
| Переполнение журнала | Отвергнутая `command_capacity` команда удаляется из очереди и сразу учитывается как потерянная |
| Удалённый манифест | Смена endpoint без изменения клиента; кэш работает офлайн |
| Сенсорный адаптер | Запрос разрешения, ограничение частоты, custom source, отказ и HTTP-origin проверены |
| Конфигурация и health | `/health` сообщает 0.4.0, лимит 50 телефонов, 50 команд TEAM и 200 игровых команд/с на устройство; манифест выдаётся сервером |

Нагрузка выполнена внутри локального процесса на 50 эмулированных клиентов, не на физических телефонах и не на опубликованном Render. Реальное наличие сенсора зависит от модели телефона и браузера; фактический гироскоп надо проверить на телефоне после публикации HTTPS-версии. Для датчиков доступ включается нажатием. Геолокация требует отдельного разрешения и должна запускаться только если она нужна конкретной игре.
