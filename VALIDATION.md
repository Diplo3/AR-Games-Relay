# Проверка v0.4

База исходников: `Diplo3/AR-Games-Relay`, main commit `8b9168517578c74bf6daf7336996e2d10d490488` (оптимизированная v0.3, проверенная пользователем на Render). Версия сохраняет путь v0.2 для 100/100 команд.

Проверено локально интеграционными WebSocket/HTTP тестами: `npm test` — **14 passed / 0 failed**.

| Сценарий | Результат |
|---|---|
| Старый протокол v0.2 | 100 команд, 100 событий HOST, 100 ACK |
| Нагрузка 50 телефонов, TEAM 1/2 | 5000 уникальных игровых команд, все обработаны; потерь 0 |
| Датчики при тех же 50 телефонах | 1000 образцов гироскопа переданы HOST, уникальность всех seq сохранена |
| Reconnect телефона и восстановление клиента | Очередь, TEAM, sessionId и seq сохранены |
| HOST недоступен / потеря ACK / рестарт relay | Повторная доставка без повторного действия HOST |
| Комната, роли, некорректные и устаревшие сообщения | Изоляция и ожидаемые ошибки |
| Удалённый манифест | Смена endpoint без изменения клиента; кэш работает офлайн |
| Сенсорный адаптер | Запрос разрешения, ограничение частоты, custom source, отказ и HTTP-origin проверены |
| Конфигурация и health | `/health` сообщает 0.4.0 и лимит 50; `relay-config.json` выдаётся сервером |

Нагрузка выполнена внутри локального процесса на 50 эмулированных клиентов, не на физических телефонах и не на опубликованном Render. Реальное наличие сенсора зависит от модели телефона и браузера; фактический гироскоп надо проверить на телефоне после публикации HTTPS-версии. Для датчиков доступ включается нажатием. Геолокация требует отдельного разрешения и должна запускаться только если она нужна конкретной игре.
