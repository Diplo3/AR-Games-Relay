# Обновление существующего GitHub / Render

База: main, commit `9c6bb43df7870ca44d71e07b5144b72233c7f98f` в https://github.com/Diplo3/AR-Games-Relay.

1. Заменить файлы в существующем репозитории содержимым этого архива. Сохранять структуру public/, test/, examples/. node_modules загружать не нужно.
2. Проверить `npm install` и `npm test` на Node >=20. Зафиксировать изменения в main или объединить проверенный pull request в ветку, которую уже отслеживает Render.
3. Открыть **существующий** сервис Render. Не выбирать New Web Service. Сохранить подключённый репозиторий, URL, тариф, переменные и отслеживаемую ветку.
4. Build: `npm install`; Start: `node server.js` — прежние команды. Если Auto-Deploy включён, дождаться сборки commit; иначе Manual Deploy → Deploy latest commit.
5. На прежнем URL открыть `/health`: version должен быть 0.3.0. Обновить страницы HOST и PLAYER. На телефоне проверить TEAM-ссылки и 100/100; затем несколько телефонов и краткий обрыв Wi-Fi/мобильной сети.

Развёртывание может разорвать активные WebSocket-соединения; проводить обновление между играми. Во время испытаний использовать один экземпляр relay: комнаты сейчас в памяти процесса, распределение по нескольким экземплярам не поддерживается.

Откат: в том же Render-сервисе развернуть исходный commit `9c6bb43...`, затем обновить браузерные страницы. Нового сервиса и миграции базы данных не требуется.

В текущей работе подготовлены исходники и пакет обновления. Публикация в GitHub и развёртывание Render не выполнялись; доступ к панели существующего сервиса не предоставлен.
